# Terrene

Terrene: a ceramics studio landing page with a real time 3D pot you can spin and stretch, scroll morphing forms and a kiln that heats as you scroll.

A single page design sample with smooth scrolling and hand built interactions. Live at https://boorussia.github.io/terrene-ceramics/

Plain HTML, CSS and JavaScript. No build step: open `index.html` or serve the folder.
